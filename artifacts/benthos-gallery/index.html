Benthos
no meshes, no lighting, no textures

Every animal here is a loop of parametric points, shaded only by how many land in the same pixel and how far away they are. Nothing is imported, nothing is sculpted — each one is a few dozen lines of trigonometry that happens to be shaped like an animal. Tap a card to orbit it, tune it, and read the source that drew it.

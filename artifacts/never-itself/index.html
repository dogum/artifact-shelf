Enigma I · a working machine

Never Itself

Press a key and a lamp lights. On the way the current runs through three wheels, turns round in a reflector and comes back by a different road. That one turn makes the machine its own inverse, so the same settings that encipher a message also decipher it. It also means a letter can never come out as itself, and that is the rule the codebreakers used against it.

II

The message

Type, and the lamps spell the cipher. Operators wrote it in groups of five and sent it by radio in Morse, with the start position of the wheels in the clear at the head. Whoever holds the same key sets the same start, types the cipher, and the lamps give back the message.

III

Where the current went

The last key you pressed, laid flat. Each column is one part of the machine with its 26 contacts; the faint lines are its wiring. The lit road goes in from the key, through the plugboard and the three wheels, turns in the reflector, and comes back out to a lamp.

Every stage before the reflector is a one-to-one wiring, and the road back runs through the same wirings the other way. So a key could only light its own lamp if the reflector sent the current back out on the contact it came in on. The reflector joins the 26 contacts in 13 pairs and never joins a contact to itself, so that never happens. Whatever the settings, Q can light any lamp but Q.

IV

Never itself, used against it

This is a real intercept: the first part of a German Army message from Operation Barbarossa, July 1941. Codebreakers often guessed a word that was probably in a message, a crib, and had to find where it sat. Slide the crib along the cipher. Wherever one of its letters lands on the same letter, that place is impossible, because the machine never enciphers a letter as itself.

Each place that survives gives a guess: these cipher letters are these plain letters, at these steps of the machine. That list was the menu for a Bombe, the electromechanical search Alan Turing designed and Gordon Welchman improved, which ran through wheel orders and start positions and stopped where every pair could be true at once.

Reconnaissance battalion from Kurtinowa, Kurtinowa, north-west of Sebezh, Sebezh, along the Fliegerstrasse toward Dubrowki, Dubrowki, Opochka, Opochka. Moved off at 18:30. Attack, infantry regiment …X stands for a full stop or a space, CH is written Q, numbers are spelled out (EINS AQT DREI NULL is 1830), and place names are sent twice.
